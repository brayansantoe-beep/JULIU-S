# Julius Burgers — proposta de novo site

Versão estática preparada para publicação no GitHub Pages.

## Estrutura
- `index.html`
- `style.css`
- `script.js`
- `assets/julius-logo.png`

## Publicar no GitHub Pages
1. Crie um repositório.
2. Envie todos os arquivos e a pasta `assets`.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Branch: `main`
6. Pasta: `/ (root)`
7. Salve.

## Antes de uso comercial
Confirme o número oficial de WhatsApp, links de pedido, preços e disponibilidade dos produtos com a Julius Burgers.
